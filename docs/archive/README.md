# Archived documentation

These notes date from November 2025, before the scan engine was rebuilt around national
registries, WHO alerts and cloned-code detection (October 2026). They describe the earlier
openFDA-and-scraper pipeline and are kept only for history.

Several claims in them are no longer true, including that the verification system was
"production-ready". For how the app works today, read the main [README](../../README.md),
[CONTRIBUTING](../../CONTRIBUTING.md) and [scripts/registry/README.md](../../scripts/registry/README.md).

The scraper setup notes (`SCRAPER_SETUP.md`, `TROUBLESHOOTING.md`) may still help if you run
`autoscrape/` locally.
